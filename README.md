# 내 반려동물 데스크탑 펫 (프로토타입 v0.1)

콤냥이처럼 화면 위에서 사는 데스크탑 펫 앱입니다. 지금은 사진 대신 플레이스홀더 고양이 캐릭터로
핵심 상호작용만 구현되어 있어요. (다음 단계에서 반려동물 사진 → 캐릭터 일러스트로 교체합니다)

## 지금 되는 기능
- 커서를 따라 눈동자가 움직여요
- 캐릭터를 클릭하고 드래그하면 쫀득하게 당겨지듯 따라오다가 놓으면 탱글하게 멈춰요
- 마우스로 캐릭터 위를 쓰다듬듯 움직이면 눈을 감고 하트가 떠올라요
- 타이핑을 하면 발을 꾹꾹이 하고, 빠르게 칠수록 살짝 붉어져요 (전역 키보드 감지 권한 필요)

## 실행 방법
```bash
npm install
npm start
```

## macOS 권한 관련 (타이핑 반응 기능)
타이핑 반응은 다른 앱에서 입력하는 것도 감지해야 해서 **손쉬운 사용(Accessibility)** 또는
**입력 모니터링(Input Monitoring)** 권한이 필요할 수 있어요.
시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 / 입력 모니터링에서 `Electron`(또는 터미널 앱)을
허용해주세요. 권한이 없어도 앱 자체는 정상 실행되고, 타이핑 반응만 비활성화됩니다.
